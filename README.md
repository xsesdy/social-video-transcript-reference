# Social Video Transcript Reference

This repository is a compact reference for taking public social-video links and turning their spoken content into downloadable text. It documents the supported link types, public-access requirements, output formats, and platform-specific limits used by the accompanying CSV.

For the live Instagram-to-text tool, visit [igscript.com](https://igscript.com/).

## Files

| File | Purpose |
| --- | --- |
| `platform-reference.csv` | A platform-by-platform table of accepted public links, retrieval conditions, outputs, and exceptions. |
| `format-guide.md` | A short guide to choosing between TXT and SRT. |
| `faq.md` | Practical questions and answers drawn from the platform pages. |

## How to use the reference

1. Find the platform row in `platform-reference.csv`.
2. Copy the public video or post URL using the method in the `how_to_copy_link` column.
3. Check the `works_when` and `does_not_work_when` columns before submitting the link.
4. Use `format-guide.md` to select TXT for plain readable text or SRT for timed subtitles.

## Scope

This is a reference, not a hosted transcription service. Platform availability can change, and content that is private, deleted, restricted, or unavailable to a signed-out viewer cannot be retrieved.
