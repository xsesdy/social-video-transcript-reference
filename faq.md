# Frequently asked questions

## Do public links work without an account?
The documented workflow uses public links. The platform pages state that no signup or email is required for the transcription workflow.

## What happens when a video has no captions?
For Instagram, TikTok, YouTube, Facebook, and X, the documented fallback is transcription from the audio. This can take longer than using an existing caption track.

## Are private videos supported?
No. The reference only covers content that a signed-out visitor can access publicly. Private, followers-only, friends-only, protected, deleted, or otherwise restricted content cannot be retrieved.

## Does an SRT file include timing?
Yes. SRT keeps timecodes for each line so subtitle text can align with the original audio.

## Does the YouTube workflow translate the transcript?
No. The documented output is returned in the language spoken in the video.
